R&D Internship — Fortinet Technologies

Duration: June 2026 — Present

Overview

Research and development internship at Fortinet Technologies, working across low-level system architecture, firmware security, GPU-accelerated machine learning, and high-performance ML implementations for time-critical applications.

Low-Level System Architecture & Security

Initially worked on low-level system architecture with a focus on UEFI firmware and platform security. Investigated the use of EFI variables for securely storing and communicating system-level state within virtual machine environments.

  • UEFI firmware and boot-time system architecture
  • EFI variable creation, persistence, and access
  • Platform security mechanisms for virtual machines
  • Low-level system initialization and firmware interaction

GPU-Accelerated Machine Learning

Subsequently worked with the AIOPS team on optimizing machine learning algorithms for time-critical applications. Developed a hardware-accelerated ML platform with a C++ backend using CUDA and NVIDIA cuML, combined with a Golang frontend.

  • C++ backend for GPU-accelerated ML execution
  • CUDA and NVIDIA cuML integration
  • Golang interface for ML inference
  • Benchmarking GPU acceleration against CPU-based implementations
  • Evaluation of throughput and CPU utilization
  • Validation of prediction accuracy after acceleration

Benchmarking demonstrated substantial improvements in throughput and reductions in CPU utilization while maintaining prediction accuracy.

High-Performance ML with Go & C++

Continued development of machine learning algorithms in Go using C++ implementations from MLpack. The implementations were benchmarked against corresponding Python implementations to evaluate performance for time-critical workloads.

  • Go bindings for C++ ML implementations
  • Integration of MLpack algorithms with Go
  • Performance benchmarking against Python counterparts
  • Throughput optimization for time-critical ML workloads

Benchmarking confirmed substantial throughput improvements compared with the corresponding Python implementations. Current work focuses on integrating the optimized Go-based ML implementations with Fortinet technologies.

Private Agentic AI Coding Assistant

In parallel, developing an agentic AI coding assistant for Fortinet designed to operate entirely within a private and offline environment. The system uses vLLM to serve private large language models and builds upon the architecture of the open-source Claude CLI, extended with custom tools, workflows, and company-specific capabilities.

  • Private LLM inference using vLLM
  • Agentic coding workflows based on open-source Claude CLI architecture
  • Custom tools and skills tailored to Fortinet development requirements
  • SQL databases for persistent project and agent context
  • Docker and containerized deployment for isolated components
  • Configuration of specialized skills and workflows for company-specific development tasks
  • Fully offline architecture for privacy and internal deployment

The system is being designed as a self-contained development assistant capable of supporting software engineering workflows while keeping source code, models, tooling, and associated data within the organization's private infrastructure.

Technologies

C++, Golang, Python, CUDA, NVIDIA cuML, MLpack, vLLM, UEFI, EFI Variables, Linux, Docker, Containers, SQL, Agentic AI, Private LLMs, Machine Learning, GPU Computing, Performance Benchmarking.
